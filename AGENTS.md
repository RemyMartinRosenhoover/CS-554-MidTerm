# AGENTS.md

This is a public, graded course submission. The working rules for coding agents live in the private companion repository `CS-554-MidTerm-agents`, cloned beside this one at `../CS-554-MidTerm-agents`. Read its `AGENTS.md` before doing anything here; if that folder does not exist, clone the private repository there first.

Two rules apply even before you read the rest:

1. Nothing about the host computer goes into this repository beyond what reproducing the project requires. No hostnames, usernames, organization names or paths, security products, or security configuration.
2. Never commit container image archives, VM images, `node_modules/`, `.env` files, keys, tokens, or credentials. CI fails on any of them.
